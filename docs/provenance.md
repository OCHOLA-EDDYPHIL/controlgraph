# Provenance

## Repository origin

This is a greenfield scaffold created for the ControlGraph Canary concept. No application source was copied from another repository. The initial text, Python, TypeScript, CSS, and Terraform configuration were authored specifically for this scaffold.

## External material

- Package and action names in configuration files refer to their upstream projects; no upstream source code is vendored here.
- The UI uses system fonts and CSS-drawn presentation only. It contains no external images, fonts, icons, or generated media.

See `THIRD_PARTY_NOTICES.md` for direct dependencies and development tools.

When code, data, media, or design assets are imported or adapted, record:

1. the upstream URL and immutable revision;
2. the author or rights holder;
3. the applicable license and required notices;

5. whether the material was modified.

Do not merge material with unclear provenance or incompatible terms.
